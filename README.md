# cosmeticos-web
Projeto Spring Boot gerado automaticamente com a estrutura mínima para a Etapa 6.

## Executar
1. Importe o banco `cosmeticos_veronica_bd.sql` no MySQL.
2. Atualize `src/main/resources/application.properties` com seu usuário/senha do MySQL.
3. No terminal, dentro da pasta do projeto, rode:
   mvn spring-boot:run
4. Endpoints de exemplo:
   GET  /api/produtos
   POST /api/produtos
