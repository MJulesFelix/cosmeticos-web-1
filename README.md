# cosmeticos-web
Título do projeto: Verônica Cosméticos;

Status do projeto: (em desenvolvimento)

Tecnologias utilizadas: Java: Linguagem de Programação e Plataforma de Desenvolvimento; MySQL: Banco de Dados;

Objetivo do software:(a que deve servir): criar um sistema desktop para o gerenciamento da loja de cosméticos, que permite a criação de cadastros de produtos, consultas de estoque e registros de vendas.

Nesta etapa foi necessário migrar o sistema desenvolvido em Java Desktop (etapas anteriores) para uma aplicação web utilizando Spring Boot, aplicando princípios de refatoração e SOLID.
